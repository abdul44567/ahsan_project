# ✨ A Story Only We Know — Kuch Khaas ✨

Yeh website aik high-end, cinematic aur deeply emotional romantic surprise website hai jo pure love, memories aur connection ke liye design ki gayi hai (no birthday, no festivals).

---

## 🌟 Files Structure
```
kuch_khass/
├── index.html     # Semantic structure, Google fonts & audio layout
├── style.css      # Luxury midnight cosmos, rose-gold accents, 3D envelope & smooth animations
├── script.js      # Central CONFIG for easy editing, interactive canvas, Web Audio synth & story flow
├── moon.png       # Floating celestial moon asset
└── README.md      # Documentation & personalization guide
```

---

## 💖 Kaise Personalize / Customize Karein?

`script.js` ke bilkul top pe line 12 se aik **`CONFIG`** object hai jahan se aap sab kuch baghair kisi code ko chhede asani se customize kar sakte hain:

1. **Naam aur Dates**:
   - `recipientName`: Jiske liye yeh gift hai (e.g., `"Amna"`, `"My Love"`).
   - `senderName`: Aapka naam (e.g., `"Abdul Rehman"`).
   - `relationshipStartDate`: Aik date (Format: `"YYYY-MM-DD"`) jisse live counter calculate hota hai (Scene 6 me).

2. **Scene 1 (Intro)**:
   - `introQuote`: Intro card par display hone wala romantic quote.

3. **Scene 2 (Suspense Whispers)**:
   - `suspenseWhispers`: Suspense ke waqt aane wale 3 cinematic lines.

4. **Scene 3 (Our Universe)**:
   - `universeMainQuote`: Typewriter se likha jane wala celestial quote.

5. **Scene 4 (Our Story Chapters)**:
   - `beginning`: Chapter 1 (Pehli mulaqat / conversation ki memory).
   - `littleThings`: Chapter 2 (Chhoti pyaari batein aur habits).
   - `memories`: Chapter 3 (Polaroid frames jin par click karne se detail modal khulta hai).
   - `reasons`: Chapter 4 (Kyun woh person itna khaas hai - deck of cards jisme shuffle button bhi hai).
   - `foreverVow`: Chapter 5 (Hold-to-sync heartbeat feature aur eternal promise).

6. **Scene 5 (A Letter From My Heart)**:
   - `letter.body`: 3D Wax seal khulne ke baad paper par typewriter effect se likha jane wala dil ka khat.

7. **Scene 6 (The Final Surprise)**:
   - `finalClimax`: Grand ending heading aur quote.
   - Shooting stars / Starlight wishes generator aur live time counter.

## 🎵 Romantic Audio / Music

- **Auto Web Audio API Synth**: Website me built-in ambient piano/pad arpeggiator chords hain jo baghair kisi internet ya mp3 download ke direct browser me play hoti hain.
- **Custom Audio Lagana**: Agar aap apna koi romantic gana ya voice note lagana chahte hain, bas `kuch_khass` folder me apni mp3 file rakhein (e.g. `music.mp3`) aur `index.html` me `<audio id="custom-audio" src="music.mp3" ...>` add kar lein.

Bas `kuch_khass/index.html` ko kisi bhi modern browser (Chrome, Edge, Safari, Firefox, mobile ya desktop) me open karein aur "Enter My Little World" par click karein!
